# Fireworks

A native Bevy fireworks lab with configurable launch speed, color palette, rocket type, and explosion shape. The show runs automatically, while manual launches and style changes are available from the keyboard or a mouse click.

## Run

From the repository root:

```sh
cargo run -p fireworks_bevy
```

## Controls

- `1`, `2`, `3`: slow, classic, or fast launch speed;
- `Z`, `X`, `C`, `V`: Aurora, Sunset, Electric, or Candy colors;
- `B`, `N`, `M`: Burst, Ring, or Willow explosion;
- `Q`, `W`, `E`, `T`: Classic, Comet, Spinner, or Heavy rocket type;
- `Space` or left click: launch a firework;
- `A`: toggle the automatic show;
- `R`: randomize speed, colors, explosion type, and rocket type.
